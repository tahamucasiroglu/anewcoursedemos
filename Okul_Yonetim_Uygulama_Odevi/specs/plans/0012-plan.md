## Risks & open questions
1. **0011 adları belirsiz.** Öneri: adım 1'de uyarla, amendment'a yaz. Gerekçe: paralel analizde tahminle kilitlemek R-07 üretir.
2. **Ses servisi elle başlıyor.** Kapalıysa özellik "kullanılamıyor" der (çökme yok). Öneri: `start-stt.ps1` + README; Windows
   hizmeti/otomatik başlatma sonra. Gerekçe: en sade, kurulu ortamı değiştirmez.
3. **Ekran kartı belleği (6 GB).** `gemma3:4b` + whisper `medium` birlikte ~4,4 GB (Promtlar 0082 ölçümü). `AiWorkGate` aynı anda
   tek iş çalıştırır. Öneri bu; yetmezse ayarla `small` modele geçilir (model `tools/ai/models`'te var).
4. **Yeniden deneme yok.** Mimari "port çağrısı zaman aşımı + yeniden deneme" diyor; etkileşimli istekte yeniden deneme bekleme
   süresini ikiye katlar. Öneri: tek deneme, ses 60 sn / metin 90 sn zaman aşımı (ilk model yüklemesi dahil), hata hemen
   "kullanılamıyor"; `docs/architecture.md`'ye istisna olarak yazılır.
5. **Pi / yerel ağ demo ayarı.** Varsayılan kapalı. LAN modunda Ollama (`OLLAMA_HOST=0.0.0.0`) ve ses servisi (`STT_HOST=0.0.0.0`)
   kimlik doğrulamasız ağa açılır. Öneri: yalnızca demo süresince, Windows güvenlik duvarı kuralı yalnızca Pi'nin adresine
   (`192.168.1.102`) izinli; düz HTTP yerel ağda kalır (B-13 ile aynı sınır). Pi tarafı ship'te kullanıcıda; bu plan Pi'ye dokunmaz.
6. **Yeni paketler (onay listesi):** NuGet `Microsoft.Extensions.Http` (Microsoft, MIT, bakımlı); npm `expo-audio` (Expo, MIT,
   SDK 58 ile uyumlu sürüm). Python tarafında yeni paket yok (standart `http.server`). `npm audit` ve `dotnet list --vulnerable`
   check'te denetler.
7. **Multipart ve üretilen istemci.** OpenAPI istemcisi multipart'ı rahat üretmeyebilir. Öneri: `src/ai/voiceNote.ts` içinde
   `fetch` + `FormData` ile tek yardımcı, oturum anahtarı `AuthSession`'dan; şema yine üretilir (api-client-fresh).
8. **Model kalitesi.** `gemma3:4b` Türkçe yeterli (Promtlar 0082 denemesi). Kalite kapısı yok (spec C-7); model adı ayardan.
9. **Expo Go / web kaydı.** `expo-audio` Expo Go'da çalışır; web'de `webm` üretir — sunucu webm'i kabul eder (PyAV çözer).
10. **Ortam:** `./scripts/doctor` → 0 fail, 93 warn (henüz kurulmamış planların test adları; bu planla ilgisiz); fast ve full
    profil bu makinede çalışıyor. Ollama (`gemma3:4b`) çalışıyor, `tools/ai/.venv` (faster-whisper 1.2.1, CUDA kütüphaneleri)
    kurulu — yalnızca adım 4, 7 ve VERIFY gözlemi için gerekli; check bunları istemez.
