# LeaveManager — frontend

React 19 + Vite + TypeScript. Kurallar `../docs/` altında (mimari, konvansiyonlar, test).

- Geliştirme: backend `http://localhost:5080` üzerinde çalışırken `npm run dev`; `/api` istekleri backend'e yönlendirilir.
- Doğrulama: projenin kökünden `./scripts/check` (lint, Prettier, typecheck burada koşar).
