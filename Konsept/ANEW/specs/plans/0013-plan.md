## Risks & open questions
1. **Yetki claim'i nerede.** Öneri: Identity rol → yetki eşlemesi aynen; model yetkileri ayrı saf kural, yalnızca Api principal'ına eklenir.
   Varsayılan (ayar yok) her iki rol `model.use:*` (Req 2). Kısıtlama ayarla (`Identity__ModelPermissions__User=openai/gpt-5-mini,…`) ve
   testte kanıtlanır; ekran yok. Arka plan işleri (0017) için çağıran `AiCaller(UserId, Permissions)` isteğin parçasıdır.
2. **Katalog düzeltmesi (seed 1.1.0).** Gerçek API'lerde: Sonnet 4.5 / Haiku 4.5 `effort` desteklemez (400), Opus 4.5 yalnızca
   `low/medium/high` (`output_config.effort`, `max` yok). Öneri: Sonnet 4.5 efor `[]`, Opus 4.5 `[low, medium, high]`; `apiModel` alanı
   (Kimi: `kimi-k2-0905-preview`, GLM: `glm-4.6`, OpenRouter: `anthropic/claude-sonnet-4.5`). Uçlar: Anthropic `/v1/messages`, OpenAI
   `/v1/chat/completions` (`max_completion_tokens`, `reasoning_effort`) + `/v1/images/generations`, OpenRouter `/api/v1/chat/completions`
   (`usage.include`), GLM `https://api.z.ai/api/paas/v4/chat/completions`, Kimi `https://api.moonshot.ai/v1/chat/completions`. Ham HTTP
   (SDK değil): beş sağlayıcıya tek tip yeniden deneme/zaman aşımı/kayıt denetimi gerekir, SDK'ların kendi tekrarları H-3'ü deler. Kesin
   model adları kullanıcının gerçek denemesinde doğrulanır; yanlışsa seed patch.
3. **Deneme ucu (spec dışı küçük ek).** Spec çağıran özellik tanımlamıyor; kullanıcı gerçek çağrıyı test edebilsin diye `POST api/ai/calls/trial`
   + "Dene" düğmesi, amaç `trial` ("deneme"). Kapının tüm kuralları aynen uygulanır, kayıt + maliyet oluşur. Öneri: kabul; 0014 gelince kalır.
4. **"Bağlantı kurulamadı" ayrımı.** `HttpRequestException` + `SocketException`/DNS (istek gitmedi) → tekrar, kayıt yok. Gönderildikten sonra
   kopma → "yanıt alınamadı" sayılır (tekrar yok, H-3 güvenli taraf).
5. **Token tahmini.** `ceil(istem karakteri / 4)` giriş token'ı × giriş fiyatı; "tahmini" işaretli. Görselde token yerine 1 görsel × fiyat tahmini.
6. **Gösterge yenileme.** 5 sn aralıklı Ajax (≤10 sn, Req 18); sekme gizliyken de çalışır (basit). Biçim Web'de (`$2,37`, `MidpointRounding.AwayFromZero`).
7. **Korunan test (A-1):** `LayoutTests` üst bar sınıf listesi `"topbar__spend passive"` → `"topbar__spend"` ve `passive.Count` 1 → 0 (spec Req 15/18
   göstergeyi canlı yapar; 0004 A-1 ile aynı desen). Diğer assert'ler aynen.
8. **Kasıtlı bozma (H-1/H-3):** yetki kontrolü kaldır → `Gateway_NoModelPermission_RejectedBeforeProvider` kırmızı · `user_id` süzgeci kaldır →
   `Gateway_UsesOnlyCallersOwnKey` kırmızı · tekrar sınırı 3→4 → `Gateway_Retryable_MaxThreeAttempts` kırmızı · zaman aşımında tekrar →
   `Gateway_Timeout_NoRetry_EstimatedRecord` kırmızı · limit kırpması kaldır → `Gateway_OutputLimit_ClampedToCatalog` kırmızı.
