## Files to change or add
**Tasarım özeti:** Kullanıcı ve ban verisinin sahibi **Identity**'dir. Ban durumu `identity.users.banned_at` (null = aktif);
her ban/ban kaldırma `identity.user_bans` satırıdır (id, user_id, kind `ban|unban`, admin_id, at, reason ≤500). Uçlar
`api/admin/users` (GET liste), `api/admin/users/{id}/ban` (POST, gövde `{reason}`), `api/admin/users/{id}/unban` (POST); hepsi
`[Authorize(Policy = admin.panel)]` (0011; yetki her istekte DB'den).
- **Ban akışı** (`AdminUserServiceBase.BanAsync`): hedef yok → 404 `admin.user_not_found`; hedef admin → 409
  `admin.cannot_ban_self` / `admin.cannot_ban_admin`; sebep >500 → 400; `UPDATE users SET banned_at=@now WHERE id=@id AND
  banned_at IS NULL` tek atomik ifade → yalnızca değiştiyse kayıt + `identity.banned` olayı + `ISessionRevoker.RevokeAllAsync`
  (0002'nin çıkış yeteneği: web oturumları, 0012 ajan cihazları + canlı bağlantıya "oturum kapandı", oturum sonu dinleyicileri).
  Zaten banlıysa idempotent başarı, ikinci kayıt yok (çift tıklama da tek ban).
- **Durdurma:** 0006 Req 16 dinleyicisi (`ProductionSessionListener`) zaten çalışan işi Durduruldu yapar, Sırada işler kalır.
  0014 Req 20 için yeni **`Concepts.Application/Concrete/ConceptSessionListener`** (`IUserSessionsEndedListener`): kullanıcının
  iki şeritteki süren partisine `RequestStop` (başlamamış konseptler çağrılmaz). Bu çıkışta da çalışır → **B-92 kapanır.**
- **Her istekte ban:** `SessionRepository.FindWithRoleAsync` banlı kullanıcının oturumunu bulmaz (JOIN'e `banned_at IS NULL`);
  refresh banlı kullanıcıda reddedilir; `AgentDeviceRepository.FindByTokenHashAsync` banlı sahibin cihazını bulmaz. Eşleştirme
  onayı web oturumu ister → banlıda yok (reddedilir). Hata bildirimi web (oturum) ve ajan (cihaz token'ı) yolunda 401, kayıt yok.
- **Giriş (Req 5, 10):** kilit önce (0002 Req 7), yanlış şifre normal sayaç; doğru şifre + banlı → 401 `identity.suspended`
  "Hesabınız askıya alınmıştır.", sayaç ve son giriş değişmez. Web `AuthPageServiceBase` kodu metne eşler.
- **Liste:** `IUserRepository.ListAsync` (Pi ölçeği, bellekte filtre/sayfa 25; arama 0010'un `AdminRange.Matches` kuralının
  Identity eşi, ≥2 karakter; durum `all|active|banned`). Klip sayısı Monitoring.Contracts `IClipStatistics.CountByUserAsync`
  (Production: canlı `production.videos` kullanıcı başına farklı konsept). Satır: ad, e-posta, kayıt, son giriş, banlı mı, rol,
  klip, `isSelf`, ban geçmişi (tür, yapan admin adı, an, sebep — yalnızca bu admin uçlarında). İçerik/profil/key alanı yok (BR-1).
- **Monitoring:** `UserDirectoryEntry` + `IsBanned` (varsayılan false) → `AdminStatisticsDto.BannedUsers`; `ActivityKinds`
  `identity.banned` → "Banlandı", `identity.unbanned` → "Ban kaldırıldı" (olay metninde sebep yok).
- **Web:** ApiClient 3 metot (`JsonElement` geçiş) · `AdminController` `/admin/kullanicilar` (GET), `/admin/kullanicilar/{id}/banla`,
  `/admin/kullanicilar/{id}/ban-kaldir` (POST, antiforgery) · `Views/Admin/Index.cshtml` Kullanıcılar sekmesi (İstatistikler'den
  sonra) + "Banlı kullanıcı" kartı + iki onay penceresi · yeni `wwwroot/js/admin-users.js` (liste, arama, filtre, sayfalama,
  pencere: sebep sayacı, >500 pasif + uyarı, işleniyor, hata pencerede, Esc/odak dönüşü) · `admin-panel.js` sekmeyi kullanıcılar
  modülüne bağlar · `UiText.resx` · `site.css` (yalnızca tema değişkenleri).
- **Testler:** `Api.Tests/AdminUsersApiTests.cs` (fake'lerle) · `AdminUsersIntegrationTests.cs` (gerçek PostgreSQL: migration,
  atomik ban, JOIN, sayım) · `Identity.Tests` giriş birim testleri · `Web.Tests/AdminUsersPageTests.cs` · Vitest
  `admin-users.test.js`. **Kurulum değişikliği (assert yok):** `InMemoryUserRepository`, `InMemorySessionRepository` (banlı → null),
  `InMemoryUserDirectory`, `InMemoryClipStatistics`, yeni `InMemoryUserBanRepository`, factory kaydı.
