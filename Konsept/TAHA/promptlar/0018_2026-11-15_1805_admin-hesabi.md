# 0018 — Admin hesabı (şifreli) + admin hesaplar ayrı

## İstek
mail:[kullanıcının e-postası]  şifre:[kullanıcının verdiği parola] olacak şekilde ekle. lütfen şifreyi şifreleme algoritması ile ekle dümdüz ekleme sanki kaydetmişiz gibi admine

(ek mesaj) bu admin için normal loginde de test edeceğim admin hesaplar ayrı olsun

> Not: e-posta ve parola bu kayda bilerek yazılmadı (gizli bilgi).

## Cevap
- Parolanın ASP.NET Identity v3 hash'i (PBKDF2-HMAC-SHA512, 100.000 tur, tuzlu) hesaplandı. Doğrulama: "Success".
- Repoya girmeyen `.env` dosyasına yalnız e-posta ve hash yazıldı. Düz parola hiçbir dosyada yok; geçici hesaplama klasörü silindi.
- Admin, API açılışında bu değerlerden bir kez oluşturulacak (seed). Kullanıcı zaten varsa üzerine yazılmayacak. Pi'ye değerler veritabanı parolası gibi gizli ortam üzerinden taşınacak.
- Admin hesapları ayrı: "Kayıt ol" yalnız normal kullanıcı açar, "ilk kayıt admin olur" kuralı kaldırıldı. Admin de normal giriş sayfasından e-postasıyla girer; giriş e-posta ya da kullanıcı adı kabul edecek.
- Uyarı: 8 haneli, yalnız rakamdan oluşan parola zayıf. LAN'da kabul edilebilir, ama sonra Ayarlar'dan değiştirmen iyi olur.
- Kural güncellendi (memory/kurallar/genel.md). Değişiklik çalışan ajana iletildi; 0.4.0 ile Pi'ye kurulacak.
